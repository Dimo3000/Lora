# Лора — голосовой ассистент для Android

Нажимаете на микрофон, задаёте вопрос голосом, Лора ищет ответ в интернете и отвечает вслух.

Ключи API, регистрация и нейросети не нужны: всё работает на бесплатных открытых сервисах.

| Что спросить | Откуда ответ |
|---|---|
| «Какая погода завтра в Казани?», «Погода» | Open-Meteo (город по умолчанию задаётся в настройках) |
| «Курс доллара», «Сколько стоит евро?» | Центробанк РФ (cbr-xml-daily.ru) |
| «Главные новости», «Новости спорта» | Google Новости (RSS) |
| «Который час?», «Какое сегодня число?» | часы телефона |
| «Привет», «Как дела?», «Расскажи анекдот», «Что ты умеешь?» | готовые ответы в приложении |
| «Кто такой Гагарин?», «Что такое фотосинтез?», «Эйфелева башня» | Википедия, затем DuckDuckGo |

Распознавание русской речи встроено в само приложение (офлайн-движок Vosk), Google для него не нужен. Для английского используется распознавание Android. Озвучка встроена в Android. Вопрос можно и напечатать. Режим разговора в настройках: после ответа Лора сразу снова слушает.

Ограничения: Лора не «думает», как ChatGPT. Она понимает вопросы по ключевым словам и зачитывает начало статьи из Википедии. На сложные вопросы вроде «как приготовить борщ» или «посоветуй фильм» ответ будет неточным или его не будет.

## Что нужно

Телефон с Android 8.0 или новее (процессор ARM, то есть почти любой телефон).

## Как собрать APK

### Вариант 1. Android Studio (проще всего)

1. Установите [Android Studio](https://developer.android.com/studio).
2. File → Open → выберите папку `voice-assistant`.
3. Дождитесь синхронизации Gradle (первый раз скачается всё нужное).
4. Подключите телефон по USB с включённой отладкой по USB и нажмите Run ▶.
   Или Build → Build App Bundle(s) / APK(s) → Build APK(s); файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

### Вариант 2. Командная строка

Перед первой сборкой скачайте модель распознавания: `bash scripts/download-vosk-model.sh` (около 45 МБ). Нужны JDK 17 и Android SDK (путь к SDK в `ANDROID_HOME` или в файле `local.properties`: `sdk.dir=/путь/к/Android/Sdk`).

```bash
./gradlew assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
adb install app/build/outputs/apk/debug/app-debug.apk
```

### Вариант 3. GitHub, без установки чего-либо

Залейте папку в репозиторий на GitHub. Файл `.github/workflows/build.yml` сам соберёт APK при каждом пуше: вкладка Actions → последний запуск → Artifacts → `lora-assistant-apk`. Скачайте APK на телефон и установите (разрешите установку из неизвестных источников).

## Первый запуск

1. Нажмите на микрофон и разрешите доступ к нему.
2. Спросите, например: «Какая погода завтра?» или «Курс доллара».
3. В настройках (шестерёнка) можно поменять город, язык и включить режим разговора.

Лору можно назначить помощником по умолчанию: Настройки телефона → Приложения → Приложения по умолчанию → Цифровой помощник.

## Устройство кода

| Файл | Что делает |
|---|---|
| `Answerer.kt` | Понимает тип вопроса и берёт ответ из нужного сервиса |
| `SpeechController.kt` | Распознавание речи и озвучка ответа |
| `AssistantViewModel.kt` | Логика: слушать → найти ответ → озвучить |
| `ui/MainScreen.kt`, `ui/SettingsScreen.kt` | Экраны на Jetpack Compose |
| `Settings.kt` | Город, язык, режим разговора |

Новый тип вопросов добавляется одной веткой в `Answerer.answer()`.
